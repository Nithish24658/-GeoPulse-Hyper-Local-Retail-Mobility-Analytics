# GeoPulse Dashboard

Week 3–4 workstream. Build a React application and embed Kepler.gl for map-based mobility analytics.

Planned views:
- Store locations and 500 m catchment areas.
- Hourly footfall heatmap / H3 hexagon layer.
- 24-hour time filter for morning and evening comparisons.
- Store-level summary and clearly labelled potential-overlap indicator.

Consume aggregate dashboard-ready data only. Do not send raw device IDs or individual GPS trails to the browser. Add loading, empty and error states when the API/data source is connected.
